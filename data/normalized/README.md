# Normalized research data

Rows under this directory are reduced, derived research representations used by the personal odds-research engine. Raw third-party API responses are not published here.

**Football data by [5DollarFootballAPI](https://5dollarfootballapi.com/).**

The 5DollarFootballAPI-derived archive stores only the fields needed for research (match result, opening/final-or-latest pre-match 1X2, Asian Handicap and goal-line structure and movement). It is not a competing raw-data feed.
