# Multi-scan value research protocol — frozen before outcome analysis

Base main: c75f7be2c87ea981487d0e4fb9b02a9e9f54dde8. Date: 2026-11-01 Asia/Bangkok.
Research only; no provider calls, production edits, registry promotion or schedule changes.

All existing outcomes are retrospective EXPLORATORY: no claim of a truly untouched historical holdout. Split by distinct football day 60% train / 20% validation / 20% retrospective test, same fixture always in one partition. All records from future dates beyond this base are prospectively reserved; existing frozen promotion gates remain mandatory.

Primary cohort: verified current OddsPapi mainline observations, separate bookmaker and provider; other current sources sensitivity only; recovered slots and historical ticks never counted as actual scans. Exact fixture IDs only, no fuzzy result joins. Conflicting identity/kickoff or FT quarantined. Prices strictly observed before kickoff. Thai football day = Bangkok timestamp minus five hours. First/last primary comparison only scans on fixture's football day; full pre-match timing analysis also includes older observations.

Predeclared descriptive bets: AH favorite at that observation (1X2 lower home/away price; AH sign fallback, home at zero tie), OU Over. Also report fixed H/A/O/U separately. These are benchmarks, NOT validated selections. Decision benchmarks require selected odds 1.80–2.20. Price-only comparison holds first selection and exact line fixed; line changes reported separately. Both sides must have valid odds and quarter lines. Two-way reciprocal normalization is a price share, NOT probability of a full win on a push/quarter-line market.

Slot classification: explicit scheduled target, nominal hour within first 15 minutes only; actual observation must lie between target minus 60 seconds and target plus 15 minutes. No rounding arbitrary manual scans into slots. Nominal 18:00 cutoff simulation uses observations <=18:00 exactly. Operational decision at completion of an on-time 18:00 scan separately allows actual time through 18:15, always before kickoff. No future substitution. B decision requires 18 slot; 15 only is setup, not a bet. C/A descriptive schedule comparison uses last eligible configured round, an oracle availability upper bound, NOT a deployable future-dependent selector. Deployable sensitivity uses first eligible round. D fixed T-3 crossing (last observation available at kickoff minus 3h); timing tuning only on train/validation, never test.

Inference: fixture-cluster percentile bootstrap 2,000 draws, seed 20261101, 95% CI. Matched comparisons paired on fixture/bookmaker/provider, bootstrap clustered on fixture. Holm familywise correction across reported primary paired price, timing and movement tests. WR=(FW+0.5HW)/(FW+0.5HW+FL+0.5HL); pushes and pushed half stakes excluded. ROI=sum Asian profit / total bets including pushes. Report all five settlement counts. Cluster samples by fixture even if multiple sides/books. Drawdown at kickoff portfolio aggregation, losses streak chronological deterministic fixture ordering; not evidence of executable bankroll path without known result timestamps.

Incremental movement model: ridge regression of realized unit return (continuous target supports quarter settlement), baseline line/odds/de-vig/league/time-to-kickoff; add 15→18 changes then all earlier same-day changes. Choose ridge alpha from 1,10,100 on validation MSE; evaluate paired fixture loss differences on retrospective test. Fit preprocessing on train only. Decision EV threshold >0, prices 1.80–2.20; uncalibrated exploratory predictions not production EV. Evaluate same complete-case cohort and baseline broader cohort separately. Include initial price/line controls in a separate movement association model. At least 150 train,80 validation,40 test and 3 leagues needed even for provisional comparison; otherwise report insufficient, not edge.

CLV only against independently verified close on same book/side/line; latest scan is not a verified close. Therefore absent reliable close: CLV N/A, and report last-scan price proxy explicitly if calculated. Asian price-share calibration uses won versus lost stake, pushes removed; not a binary full-win Brier score.

Two-round noninferiority: prospective margin -0.02 unit ROI per bet; one-sided 95% lower CI for B−A must exceed -0.02, coverage loss <=5 percentage points, missed validated opportunities <=5%, measured request savings >=25%. These are proposed research acceptance thresholds, not changes to frozen validation gates. Failure to reject zero is NOT noninferiority. Prospective target determined from paired-difference variance, 80% power, one-sided alpha .05; minimum frozen sample, >=3 leagues, >=8 weeks, >=60 football days, then untouched confirmation. Preserve all production scans in shadow mode.
